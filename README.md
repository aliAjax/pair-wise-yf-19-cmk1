# hxyfront-62007 植物标本馆入库

源提示词编号：9

植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面包含入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录、单份标本详情页，以及**柜位迁移台账**。

## 柜位迁移台账规则

- 只有**已入库且资料完整**（已压制，采集号/物种/采集人/采集地点/海拔/生境齐全）的标本能申请迁柜；
- 目标柜位**温湿度档需一致**且**有余额**（在柜占用 + 迁移预留都计入余额）；
- **同类申请只保留一条**：同一标本已有进行中申请或同批重复，任一不合法则**整次拒绝**，原柜位与队列不变；
- 迁移中**冻结鉴定和借阅**，来源柜继续保留标本名额，目标柜仅做预留；
- 接收时**柜位不符或目标已占用**：退回来源柜并生成差异复核，未结前不得再迁；
- 取消**只释放目标预留**，标本仍在来源柜；
- 柜位记录、详情页与本地数据同步；旧记录一律按**未迁移**处理，数据写入 localStorage，刷新后保留。

## 业务文件拆分

| 文件 | 职责 |
| --- | --- |
| `src/herbarium/model.ts` | 数据模型：标本、柜位、迁移申请、差异复核类型；示例数据；本地存储与旧数据归一化 |
| `src/herbarium/migrationRules.ts` | 迁移规则（纯函数）：资格校验、批量申请、接收核对、取消、差异复核、容量与冻结推导 |
| `src/herbarium/viewState.tsx` | 视图状态：持久化领域状态 + 筛选/弹窗/草稿等视图状态与全部动作封装 |

视图组件：`Workbench.tsx`（入库工作台）、`Cabinets.tsx`（柜位记录）、`Ledger.tsx`（迁柜台账）、`Detail.tsx`（标本详情）、`ui.tsx`（共享组件）。
